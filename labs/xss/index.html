O que é XSS (Stored)?

Stored XSS (Cross-Site Scripting Armazenado) ocorre quando um payload malicioso inserido por um usuário é armazenado permanentemente no servidor (banco de dados, arquivos, etc.) e posteriormente renderizado de forma insegura nas páginas visualizadas por outros visitantes.

Quando o navegador da vítima renderiza a página contendo o payload sem escapar caracteres especiais (como < e >), o script malicioso é interpretado e executado no contexto da sessão do usuário afetado.

Roteiro do Laboratório

  • Envie um comentário comum no modo Vulnerável (ex: "Ótimo lab!").
  • Explore: Envie um payload XSS no comentário (ex: <img src=x onerror="triggerXSSAlert()">) no modo Vulnerável.
  • Mude para o modo Seguro e envie o mesmo payload. Veja que o HTML é escapado e renderizado com segurança como texto.
  • Examine a diferença de código e aprenda a corrigir.

Visualizador de Código (Frontend DOM Rendering)

// Renderização de Comentários - Modo Vulnerável
function renderCommentsVuln(comments) {
  const wall = document.getElementById('comments-wall');
  wall.innerHTML = '';

  comments.forEach(comment => {
    const el = document.createElement('div');
    el.className = 'comment-item';
    
    // VULNERABILIDADE XSS: Uso de innerHTML com entrada de usuário
    // permite que tags HTML e scripts injetados sejam executados diretamente.
    el.innerHTML = `
      <div class="comment-meta">
        <span class="comment-author">${comment.author}</span>
      </div>
      <div class="comment-body">${comment.text}</div>
    `;
    wall.appendChild(el);
  });
}
// Renderização de Comentários - Modo Seguro
function renderCommentsSecure(comments) {
  const wall = document.getElementById('comments-wall');
  wall.innerHTML = '';

  comments.forEach(comment => {
    const el = document.createElement('div');
    el.className = 'comment-item';

    const meta = document.createElement('div');
    meta.className = 'comment-meta';
    
    const authorSpan = document.createElement('span');
    authorSpan.className = 'comment-author';
    // DEFESA: textContent escapa caracteres especiais e trata como texto literal
    authorSpan.textContent = comment.author;
    meta.appendChild(authorSpan);

    const body = document.createElement('div');
    body.className = 'comment-body';
    // DEFESA: textContent previne a execução de códigos injetados (evita XSS)
    body.textContent = comment.text;

    el.appendChild(meta);
    el.appendChild(body);
    wall.appendChild(el);
  });
}
