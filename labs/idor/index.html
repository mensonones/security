O que é IDOR?

IDOR (Insecure Direct Object Reference - Referência Direta Insegura a Objetos) ocorre quando um sistema web expõe uma referência a um objeto de banco de dados interno ou arquivo sem realizar a verificação de autorização apropriada.

Um atacante pode manipular parâmetros de entrada (como IDs na URL ou corpo da requisição) para obter acesso não autorizado a dados confidenciais de outros usuários.

Roteiro do Laboratório

  • Faça uma requisição no modo Vulnerável para obter a fatura de Alice (ID 101).
  • Altere o ID na URL para 102 e tente ler o prontuário de Bob.
  • Mude a rota para Seguro e execute a requisição de Bob novamente.
  • Examine a diferença de código e aprenda a corrigir.

Visualizador de Código (Node.js/Express)

app.get('/api/idor/vulnerable/documents/:id', checkAuth, (req, res) => {
  const docId = parseDocumentId(req.params.id);

  if (docId === null) {
    return res.status(400).json({ error: 'ID inválido.' });
  }

  const doc = documents[docId];

  if (!doc) {
    return res.status(404).json({ error: 'Não encontrado.' });
  }

  // IDOR: Nenhuma validação se o documento pertence
  // ao usuário autenticado na requisição (req.userId).
  res.json({ document: doc });
});
app.get('/api/idor/secure/documents/:id', checkAuth, (req, res) => {
  const docId = parseDocumentId(req.params.id);

  if (docId === null) {
    return res.status(400).json({ error: 'ID inválido.' });
  }

  const doc = documents[docId];

  if (!doc) {
    return res.status(404).json({ error: 'Não encontrado.' });
  }

  // Validação se o proprietário do documento
  // corresponde ao usuário logado na sessão (req.userId).
  if (doc.ownerId !== req.userId) {
    return res.status(403).json({
      error: 'Acesso Negado: Você não tem autorização.'
    });
  }

  res.json({ document: doc });
});
